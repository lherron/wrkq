The Task owns a single unit of human-agent work: identity, path placement, lifecycle state, routing, workflow metadata, content, and audit stamps.

Task

A persisted work item inside one wrkq container, carrying lifecycle state, assignment, cross-project routing, workflow linkage, task text, and audit metadata.

type Task = { // Persisted wrkq work item rendered with domain.Task JSON field names.
  uuid: UUIDv4String // Primary immutable database identity for selectors, relations, comments, and attachments.
  id: `T-${number}` // Friendly task id allocated by task_seq and shown to humans and agents.
  slug: Slug // Lowercase path segment unique within the parent project/container.
  title: string // Human-readable task title.
  project_uuid: UUIDv4String // Container UUID that owns this task's path placement.
  requested_by_project_id?: string // Optional source project id when this task was requested by another project.
  assigned_project_id?: string // Optional destination project id for cross-project routing.
  state: 'idea' | 'draft' | 'open' | 'in_progress' | 'completed' | 'blocked' | 'cancelled' | 'archived' | 'deleted' // Lifecycle or visibility state accepted by domain validation.
  priority: 1 | 2 | 3 | 4 // Relative priority where 1 is highest and 4 is lowest.
  kind: 'task' | 'subtask' | 'spike' | 'bug' | 'chore' // Work-item category accepted by domain validation.
  parent_task_uuid?: UUIDv4String // Optional parent task UUID; subtasks are limited to one nesting level.
  assignee_actor_uuid?: UUIDv4String // Optional actor UUID for the currently assigned human or agent.
  acknowledged_at?: RFC3339Timestamp // Optional timestamp marking acknowledgement of a routed request.
  resolution?: 'done' | 'wont_do' | 'duplicate' | 'needs_info' // Optional final or triage resolution accepted by domain validation.
  cp_project_id?: string // Optional control-plane project binding for async coordination.
  cp_work_item_id?: string // Optional stable control-plane WorkItem binding across multiple runs.
  cp_run_id?: string // Optional control-plane run id for the current or latest async run.
  session_id?: string // Optional JSON field backed by the cp_session_id database column.
  run_status?: 'queued' | 'running' | 'completed' | 'failed' | 'cancelled' | 'timed_out' // Optional async run status accepted by domain validation.
  workflow_preset?: string // Optional workflow preset name; must appear with preset_version and phase when set.
  preset_version?: number // Optional workflow preset version paired with workflow_preset and phase.
  phase?: string // Optional workflow phase paired with workflow_preset and preset_version.
  risk_class?: 'low' | 'medium' | 'high' // Optional workflow risk class accepted by domain validation.
  start_at?: RFC3339Timestamp // Optional planned or actual start timestamp.
  due_at?: RFC3339Timestamp // Optional due timestamp for sorting and planning.
  labels?: JSONText // Optional JSON array stored as text in the database/domain field.
  meta?: JSONText> // Optional JSON object stored as text for tool or agent metadata.
  description: string // Markdown task body used for context, acceptance criteria, and progress handoff.
  specification: string // Additional specification text stored separately from description.
  etag: number // Optimistic concurrency token incremented on task mutation.
  created_at: RFC3339Timestamp // Timestamp when the task row was created.
  updated_at: RFC3339Timestamp // Timestamp touched by updates for recency and audit views.
  completed_at?: RFC3339Timestamp // Optional timestamp set when state transitions to completed.
  archived_at?: RFC3339Timestamp // Optional timestamp set when the task is archived.
  deleted_at?: RFC3339Timestamp // Optional timestamp set when state transitions to deleted and cleared on restore.
  created_by_actor_uuid: UUIDv4String // Actor UUID that created the task.
  updated_by_actor_uuid: UUIDv4String // Actor UUID responsible for the most recent mutation.
}

type UUIDv4String = string // Lowercase UUIDv4 string accepted by domain validation.
type RFC3339Timestamp = string // ISO-8601/RFC3339 timestamp string used by Go time serialization.
type Slug = string // Lowercase [a-z0-9-] path segment beginning with an alphanumeric character.
type JSONText<T> = string // JSON payload persisted as SQLite TEXT while retaining the indicated semantic shape.

02 Sources

Provenance

The contract is normalized from Go JSON tags in internal/domain/types.go, enum validators in internal/domain/validation.go, and task-table migrations that add lifecycle, routing, CP linkage, metadata, specification, and workflow fields.

Scope

Only the wrkq task is rendered. Related comments, relations, attachments, evidence, and workflow tables are intentionally out of scope for this standalone task page.
