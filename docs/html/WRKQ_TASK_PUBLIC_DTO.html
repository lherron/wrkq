DTO families

Three public Task DTO contracts

Each public Task DTO surface owns a different slice of the contract. Do not treat internal/domain.Task as the single source of truth for every caller: it anchors only the persisted storage fields. The canonical RPC task resource is internal/wrkqapi.WrkqTask, and the legacy CLI read shape is internal/wrkqapi.WrkqTaskCatView.

rpc cli storage
DTO / package Surfaces Contract & casing
internal/wrkqapi.WrkqTask rpcwrkq.task.create, wrkq.task.show, wrkq.task.list Canonical stable task resource DTO. Field names are camelCase (projectUuid, createdAt, assigneePrincipalRef) and are covered by the workrpc DTO catalog and protocol schema hash. This is the contract for new JSON-RPC consumers.
internal/wrkqapi.WrkqTaskCatView cliwrkq cat --json, wrkq.task.catView Server-owned compatibility read projection that reproduces a legacy wrkq cat --json object byte-for-byte. Field names are snake_case (project_uuid, artifact_dir) and it carries read decorators (path, artifact dir, comments, relations, blockers). It is explicitly not the canonical RPC resource DTO.
internal/domain.Task storetasks table / domain JSON The persisted task struct. Its JSON tags and pointer/omitempty rules are authoritative for persisted storage-backed fields only — not for the whole public API.

02 Task DTO

This ledger documents the internal/domain.Task persisted surface and the snake_case WrkqTaskCatView read projection layered on top of it: it starts with porcelain/read-rendered decorators, then groups the persisted fields by identity, routing, lifecycle, workflow, content, created attribution, updated attribution, deletion, and deprecated compatibility. For the camelCase RPC resource see internal/wrkqapi.WrkqTask and the workrpc DTO catalog.

Public DTO

Task

A single wrkq work item with porcelain fields first and persisted fields grouped by role.

type Task = { // Full public wrkq task DTO with porcelain fields first and persisted fields grouped by role.
  // Porcelain-rendered placement and display fields
  path?: string // Resolved container/task path from v_task_paths.
  artifact_dir?: string // Local artifact directory derived from the task id for generated task outputs.
  project_id?: `P-${number}` | string // Friendly id of the owning project/container.
  parent_task_id?: `T-${number}` | string // Friendly id of the parent task when parent_task_uuid is present.
  assignee?: string // Display handle resolved from assignee_principal_ref or <strong>Legacy</strong> actor slug.
  assignee_uuid?: UUIDv4String // <strong>Legacy</strong> actor UUID alias exposed by read DTOs for local actor-backed assignments.
  created_by?: string // Display handle resolved from created_by_principal_ref or <strong>Legacy</strong> creator actor slug.
  created_by_actor?: string // <strong>Legacy</strong> creator actor slug exposed by wrkq cat --json.
  updated_by?: string // Display handle resolved from updated_by_principal_ref or <strong>Legacy</strong> updater actor slug.
  blocked_by?: { // Incomplete blocking tasks included by richer CLI reads.
    id: `T-${number}` | string // Friendly id of an incomplete blocking task.
    state: TaskState // Lifecycle state of that blocking task.
  }[]
  comments?: CommentReadDTO[] // Non-deleted task comments included unless comments are explicitly excluded.
  relations?: TaskRelationReadDTO[] // Task relations included by rich reads when relation data is loaded.

  // Identity and placement fields
  uuid: UUIDv4String // Immutable task identity used by selectors, comments, attachments, relations, events, and storage joins.
  id: `T-${number}` | string // Human-facing task id allocated by task_seq and the tasks_ai_friendly trigger.
  slug: Slug // Task path segment unique inside the owning project/container.
  title: string // Human-readable task title stored directly on the task row.
  project_uuid: UUIDv4String // Owning container UUID that places the task in the container hierarchy.

  // Routing and assignment fields
  requested_by_project_id?: string // Source project id when the task was requested from another project.
  assigned_project_id?: string // Destination project id when cross-project routing assigns the task elsewhere.
  parent_task_uuid?: UUIDv4String // Parent task UUID when this task is modeled as a subtask.
  assignee_actor_uuid?: UUIDv4String // <strong>Legacy</strong> local actor assignment cache; prefer assignee_principal_ref for canonical ownership.
  assignee_principal_ref?: PrincipalRef // Canonical assignee principal for current agent or external-principal ownership.
  acknowledged_at?: RFC3339Timestamp // Time a routed request or assignment was acknowledged.

  // Lifecycle and schedule fields
  state: TaskState // Current lifecycle state used for filtering, visibility, and lifecycle timestamps.
  priority: 1 | 2 | 3 | 4 // Relative priority where 1 is highest and 4 is lowest.
  kind: TaskKind // Work-item classification used for filtering, display, and subtask invariants.
  resolution?: TaskResolution // Optional outcome classification such as done, duplicate, or needs_info.
  start_at?: RFC3339Timestamp // Planned or actual start timestamp used by scheduling and planning views.
  due_at?: RFC3339Timestamp // Due timestamp used for sorting, filtering, and planning views.

  // Workflow fields
  workflow_preset?: string // Workflow preset name; must be set together with preset_version and phase or all three must be absent.
  preset_version?: number // Workflow preset version paired with workflow_preset and phase.
  phase?: string // Current workflow phase paired with workflow_preset and preset_version.
  risk_class?: TaskRiskClass // Workflow risk classification when workflow metadata is active.

  // Content and metadata fields
  labels?: JSONText<string[]> // JSON array stored as SQLite TEXT in the domain field.
  meta?: JSONText<Record<string, unknown>> // JSON object stored as SQLite TEXT for tool or agent metadata.
  description: string // Main markdown task body containing context, acceptance criteria, and handoff details.
  specification: string // Additional specification text stored separately from description.
  etag: number // Optimistic concurrency token incremented on task mutation.

  // Created fields
  created_at: RFC3339Timestamp // Timestamp when the task row was created.
  created_by_actor_uuid?: UUIDv4String // <strong>Legacy</strong> local creator actor cache retained for compatibility with older actor-backed data.
  created_by_principal_ref?: PrincipalRef // Canonical principal that created the task after external principal attribution.
  created_by_scope_ref?: ScopeRef // Runtime scope that created the task when available.

  // Updated fields
  updated_at: RFC3339Timestamp // Timestamp touched by updates for recency and audit views.
  updated_by_actor_uuid?: UUIDv4String // <strong>Legacy</strong> local updater actor cache retained for compatibility with older actor-backed data.
  updated_by_principal_ref?: PrincipalRef // Canonical principal responsible for the latest task mutation.
  updated_by_scope_ref?: ScopeRef // Runtime scope responsible for the latest mutation when available.

  // Deleted and archived fields
  completed_at?: RFC3339Timestamp // Current completion timestamp set while state is completed; cleared when reopened.
  archived_at?: RFC3339Timestamp // Timestamp set when state transitions to archived.
  deleted_at?: RFC3339Timestamp // Timestamp set when state transitions to deleted and cleared on restore.
  deleted_by_principal_ref?: PrincipalRef // Canonical principal that soft-deleted the task, cleared when restored.
  deleted_by_scope_ref?: ScopeRef // Runtime scope that soft-deleted the task, cleared when restored.

  // Deprecated compatibility fields
  sdk_session_id?: string | null // Deprecated database-only SDK session column; domain.Task marks it json:'-'.
}

type CommentReadDTO = { // Minimal comment shape embedded in task read responses.
  id: string // Friendly comment id.
  created_at: RFC3339Timestamp // Comment creation timestamp.
  body: string // Markdown comment body.
  principal_ref?: PrincipalRef // Canonical comment author principal when available.
  scope_ref?: ScopeRef // Runtime scope that created the comment when available.
  actor_slug?: string // <strong>Legacy</strong> author actor slug when principal attribution is unavailable.
  actor_role?: 'human' | 'agent' | 'system' // <strong>Legacy</strong> actor-table role for display and filtering.
}

type TaskRelationReadDTO = { // Task relation shape embedded in richer task read responses.
  kind: 'blocks' | 'relates_to' | 'duplicates' | string // Relation kind recorded for the directed edge.
  direction?: 'outgoing' | 'incoming' | string // Direction relative to the task being read when the caller asks for relations.
  task_id?: `T-${number}` | string // Friendly id of the related task when loaded for display.
  task_uuid?: UUIDv4String // Stable UUID of the related task when loaded for joins.
  task_slug?: string // Slug of the related task when loaded for display.
  task_title?: string // Title of the related task when loaded for display.
  created_by_id?: string // Principal handle or <strong>Legacy</strong> actor id that created the relation.
}
